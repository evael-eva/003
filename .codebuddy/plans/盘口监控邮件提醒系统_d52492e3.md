## Product Overview

一个基于PyQt5的足球比赛盘口实时监控与邮件提醒系统，从7M体育(titan007.com)获取赛事初盘数据，支持按亚盘/大小球盘口条件筛选比赛，实时监控盘口水位变化和进球数，达到用户设定阈值时触发弹窗、声音报警和邮件通知。

## Core Features

### 一、盘口筛选模块

- 使用DrissionPage浏览器自动化访问 https://live.titan007.com/ 页面
- 点击"盘*"按钮打开指数筛选弹窗，支持亚盘初盘筛选（勾选/取消勾选对应复选框）
- 支持大小球初盘筛选（切换到"进球数"tab后勾选）
- 两个筛选通过复选框独立控制启用状态，都启用时合并结果并区分来源（标注是亚盘筛选还是大小球筛选出来的）

### 二、实时监测模块

- 实时比分监测：从页面获取当前比赛比分和时间
- 实时进球数统计：统计全场进球数、上半场进球数、下半场进球数
- 盘口水位监测：通过requests访问亚盘详情页(https://vip.titan007.com/changeDetail/handicap.aspx?id={id}&companyID=3&l=0)和大小球详情页(https://vip.titan007.com/changeDetail/overunder.aspx?id={id}&companyID=3&l=0)，使用BeautifulSoup解析表格获取实时主队赔率、盘口、客队赔率等数据

### 三、功能设置窗口

- 数值输入窗口：可设定目标进球数(全场)、目标水位阈值（主队赔率/客队赔率）、刷新间隔时间
- 上半场进球提醒开关：CheckBox控制是否启用上半场进球提醒
- 下半场进球提醒开关：CheckBox控制是否启用下半场进球提醒
- 邮件设置：收件人邮箱、发件人邮箱、SMTP服务器配置

### 四、提醒触发规则

1. 上下半场达到进球提醒：上半场或下半场出现进球时触发（需对应开关开启）
2. 大小球进球数达标提醒：全场实时总进球数达到用户设定的目标值时触发
3. 水位达标提醒：亚盘主队/客队赔率或大小球大球/小球赔率达到设定阈值时触发

### 五、提醒输出方式

- 弹窗提醒：QMessageBox弹出警告窗口
- 声音报警：winsound播放系统提示音
- 邮件通知：smtplib发送SMTP邮件到指定收件人

## Tech Stack

- **UI框架**: Python 3.x + PyQt5 (与现有项目保持一致)
- **浏览器自动化**: DrissionPage (用于操作live.titan007.com筛选页面)
- **HTTP请求**: requests + BeautifulSoup4 (用于请求亚盘/大小球详情页并解析)
- **音频播放**: winsound (Windows系统声音报警)
- **邮件发送**: smtplib + email (SMTP邮件通知)
- **多线程**: QThread (监控线程与UI线程分离)
- **数据解析**: BeautifulSoup4 (HTML表格解析)

### 核心模块设计

1. **FilterController** - 负责DrissionPage浏览器操作，完成盘口筛选流程
2. **OddsFetcher** - 负责requests请求亚盘/大小球详情页并解析（复用需求中的_parse_asian_table/_parse_overunder_table逻辑）
3. **MonitorEngine** - QThread子类，定时拉取数据并检查触发规则
4. **AlertManager** - 统一管理弹窗+声音+邮件三种通知方式
5. **EmailService** - 封装SMTP邮件发送功能

### 数据流

```
用户设置筛选条件 → FilterController操作浏览器筛选 → 获取比赛列表
→ OddsFetcher批量请求每场比赛的亚盘/大小球初盘 → 展示在表格中
→ 用户勾选要监控的比赛并设置每场比赛的阈值 → MonitorEngine启动定时监控
→ 定时请求详情页 → 解析最新数据 → 比对阈值 → 触发AlertManager
→ 弹窗+声音+邮件三路同时通知
```

## Implementation Notes

1. **编码处理**: titan007网页返回gb2312编码，需用`response.content.decode('gb2312', errors='ignore')`处理
2. **Cookie维护**: 亚盘/大小球详情页需要携带有效cookie才能正常返回数据，从请求头文件中提取cookie并在请求中使用
3. **浏览器资源**: DrissionPage创建的浏览器实例需要在停止监控时正确quit()释放
4. **防重复告警**: 同一比赛的同一触发条件在一定时间间隔内不重复告警（默认60秒冷却期）
5. **性能考虑**: 批量请求多场比赛数据时使用time.sleep(0.3~0.5)避免请求过快被封
6. **解析逻辑**: 直接复用需求.txt中提供的_parse_asian_table和_parse_overunder_table方法代码

## 设计概述

这是一个桌面端(PyQt5)应用，整体设计采用深色主题搭配亮色强调色的现代专业风格。界面分为三个核心区域：左侧筛选设置区、中间比赛数据展示区、右侧监控设置面板。整体布局紧凑高效，信息密度高但层次分明。

## 页面规划（共3个主要界面区块）

### 区块一：顶部导航栏

包含应用程序标题"盘口监控与邮件提醒"、全局控制按钮（开始监控/停止监控）、状态指示灯。背景使用深色渐变，标题使用粗体白色字体。右侧显示当前运行状态和已监控比赛数量。

### 区块二：左侧盘口筛选面板（折叠式GroupBox）

- **亚盘筛选区**: 包含一个QListWidget展示所有可选的亚盘盘口选项（平手、平/半、半球、半/一、一球等），支持多选checkbox。顶部有"启用亚盘筛选"复选框。
- **大小球筛选区**: 类似结构，展示大小球盘口选项（2/2.5、2.5、2.5/3、3等）。顶部有"启用大小球筛选"复选框。
- **操作按钮**: "执行筛选"按钮触发DrissionPage浏览器筛选操作。
- 风格：浅灰色背景，圆角边框，选中项高亮蓝色。

### 区块三：中央比赛列表表格（核心区域）

- **表头**: 复选框 | 比赛信息(时间/主队vs客队) | 比分 | 亚盘初盘(主赔/盘口/客赔) | 大小球初盘(大球/盘口/小球) | 来源标签 | 状态
- **行样式**: 交替行颜色（白色/浅灰），被勾选的比赛行有蓝色左边框标识
- **交互**: 点击复选框勾选比赛后，该行下方展开独立的监控参数设置行（内嵌控件），包含：目标全场进球数SpinBox、上半场进球提醒开关、下半场进球提醒开关、亚盘主队水位阈值、亚盘客队水位阈值、大球水位阈值、小球水位阈值
- **来源标签**: 用彩色Tag区分"亚盘筛选"(蓝色标签)和"大小球筛选"(绿色标签)
- 表格底部显示"共X场比赛，已选择Y场监控"

### 区块四：右侧监控设置面板

- **全局刷新间隔**: SpinBox(秒)
- **邮件设置**: 收件人输入框(LineEdit)、SMTP服务器、端口、账号、密码
- **测试邮件**: 发送测试邮件按钮
- **提醒开关组**: 
- 启用弹窗提醒(CheckBox, 默认开)
- 启用声音提醒(CheckBox, 默认开)  
- 启用邮件提醒(CheckBox, 默认开)
- **运行日志**: 只读文本框，显示最近的操作日志和告警记录

### 区块五：底部状态栏

显示最后更新时间、本次会话累计告警次数、网络连接状态指示器
