**问题**: 
- 代理已经被标记为失效

- 导致程序一直报错，无法正常运行

## 🔍 根本原因

### 问题分析

**失效标记时保存的格式**:
```python
# _mark_proxy_failed() 接收到的 proxy_addr
"http://DED2BDD0:3FFA175501A1@112.49.20.228:20021"

# 处理后（去掉 http://）
"DED2BDD0:3FFA175501A1@112.49.20.228:20021"  ← 保存到 failed_proxies
```

**检查时使用的格式**:
```python
# _use_next_proxy() 中的 proxy
"112.49.20.228:20021"  ← 从 proxy_pool 中获取

# 检查
if proxy not in self.failed_proxies:  # "112.49.20.228:20021" not in {"DED2BDD0:3FFA175501A1@112.49.20.228:20021"}
    # True! 因为两者不匹配
    return  # 继续使用这个"失效"的代理
```

**核心问题**: 
- 失效集合中存储的是: `DED2BDD0:3FFA175501A1@112.49.20.228:20021`
- 检查时使用的是: `112.49.20.228:20021`
- **字符串不匹配** → 检查失败 → 继续使用该代理

---

## ✅ 修复方案

### 修复1: 统一失效标记格式

**文件**: `odds_fetcher.py` - `_mark_proxy_failed()` 方法

**修改前**:
```python
def _mark_proxy_failed(self, proxy_addr):
    if proxy_addr.startswith('http://'):
        proxy_addr = proxy_addr[7:]  # 只去掉 http://
    
    self.failed_proxies.add(proxy_addr)
    # 保存: "DED2BDD0:3FFA175501A1@112.49.20.228:20021"
```

**修改后**:
```python
def _mark_proxy_failed(self, proxy_addr):
    # v8.4修复: 提取纯 IP:端口 部分（去掉 http:// 和认证信息）
    if proxy_addr.startswith('http://'):
        proxy_addr = proxy_addr[7:]  # 去掉 http://
    
    # 如果包含 @，说明有认证信息，需要提取 IP:端口
    if '@' in proxy_addr:
        # 格式: username:password@IP:PORT
        proxy_addr = proxy_addr.split('@')[1]  # 取 @ 后面的部分
    
    self.failed_proxies.add(proxy_addr)
    # 保存: "112.49.20.228:20021"  ← 与 proxy_pool 中的格式一致
```

## 🔄 完整的工作流程

```
1. 初始化代理池
   proxy_pool = ["IP1:PORT1", "IP2:PORT2", ...]

2. 使用代理
   proxy = "IP1:PORT1"
   auth = "user:pass"
   proxy_url = f"http://{auth}@{proxy}"
   # "http://user:pass@IP1:PORT1"

3. 请求失败（407错误）
   _mark_proxy_failed("http://user:pass@IP1:PORT1")
   ↓
   去掉 http:// → "user:pass@IP1:PORT1"
   ↓
   去掉认证 → "IP1:PORT1"
   ↓
   failed_proxies.add("IP1:PORT1")

4. 下次检查
   proxy = "IP1:PORT1"  (从 proxy_pool)
   if proxy not in failed_proxies:  # "IP1:PORT1" not in {"IP1:PORT1"}
       → False → 跳过这个代理
   else:
       → 切换到下一个

5. 日志显示
   display_proxy = "IP1:PORT1"  (去掉认证信息)
   print(f"[请求开始] - 使用代理: {display_proxy}")
```

## 📞 常见问题

### Q1: 为什么会有认证信息在URL中？

**A**: 
- 你的代理服务商需要用户名密码认证
- requests库支持这种格式: `http://user:pass@IP:PORT`
- 这是标准的HTTP代理认证方式

### Q2: 为什么不直接用IP:端口作为键？

**A**: 
- proxy_pool 中存储的就是 `IP:PORT` 格式
- 为了保持一致性，failed_proxies 也应该用相同格式
- 这样可以直接用 `in` 操作符检查

### Q3: 日志中隐藏认证信息会影响调试吗？

**A**: 
- 不会，调试时只需要知道是哪个IP
- 认证信息是敏感的，不应该暴露在日志中
- 如果需要查看完整URL，可以在代码中临时添加调试日志

### Q4: 如果代理不需要认证怎么办？

**A**: 
- 代码已经处理了这种情况
- 如果没有认证信息，`@` 不在URL中
- 直接使用原始URL显示即可
