# 邮件伪装功能说明 - 美股股票信息

## ✅ 功能概述

为了保护用户隐私和避免敏感信息泄露，邮件通知系统已全面升级为**美股股票信息伪装模式**。

所有通过邮件发送的告警内容都会自动替换敏感词汇，伪装成美股股票市场监测信息。

## 🔧 技术实现

### 1. 敏感词替换函数

```python
@staticmethod
def _sanitize_email_content(text):
    """
    替换邮件内容中的敏感字眼，伪装成美股股票信息
    :param text: 原始文本
    :return: 替换后的文本
    """
    # 敏感词替换映射表
    replacements = {
        '比赛': '股票',
        '主队': 'AAPL',
        '客队': 'TSLA',
        '进球': '涨幅',
        '球': '%',
        '盘口': '指数',
        '亚盘': '技术指标',
        '水位': '收益率',
        '上半场': '早盘',
        '下半场': '午盘',
        # ... 更多替换规则
    }
    
    # 执行替换
    result = text
    for old_word, new_word in replacements.items():
        result = result.replace(old_word, new_word)
    
    return result
```

### 2. 邮件发送流程

```python
def trigger_alert(self, match_id, alert_type, message):
    # ... 其他逻辑
    
    if self.email_enabled and self.email_config.get('receiver_email'):
        # 1. 生成原始内容
        original_subject = f"[盘口监控] {alert_type_name} - {timestamp}"
        original_body = f"比赛ID: {match_id}\n..."
        
        # 2. 替换敏感词
        sanitized_subject = self._sanitize_email_content(original_subject)
        sanitized_body = self._sanitize_email_content(original_body)
        
        # 3. 添加伪装标题
        subject = f"[美股股票信息] {sanitized_subject}"
        body = sanitized_body
        
        # 4. 发送邮件
        t = threading.Thread(target=self._send_email, args=(subject, body,))
        t.start()
```

## ⚠️ 注意事项

### 1. 替换顺序

替换是按顺序进行的，需要注意替换的顺序可能影响结果。

**示例**:
```python
# 如果先替换"球"为"%"
"进球" → "进%"

# 再替换"进球"为"涨幅"（不会匹配，因为已经变成"进%"）
```

**解决方案**: 
- 优先替换长词（如"进球"）
- 再替换短词（如"球"）
- 当前实现已按此顺序排列

---

### 2. 上下文理解

某些词在不同上下文中可能有不同含义，当前实现是全局替换。

**示例**:
- "球队" → "公司"（正确）
- "球员" → "公司员工"（可能不准确）

**改进建议**: 
- 如需更精确的替换，可以使用正则表达式
- 或基于上下文的智能替换

---

## 📝 日志记录

### 告警日志（不受影响）

**重要**: 保存到 `alert_logs/` 的JSON日志文件**不会**应用伪装，仍然保留原始内容。

**原因**:
- 日志用于数据分析和统计
- 需要保持数据的准确性
- 方便后续查询和追溯

**示例**:
```json
{
  "timestamp": "2026-04-17 14:30:25",
  "match_id": "2816062",
  "alert_type": "goal_reached",
  "alert_type_name": "全场进球达标",
  "message": "⚽ 全场进球达标! A队 vs B队: 全场3球(阈值3), 比分 2-1"
}
```
