## 📋 敏感词替换映射表

### 比赛相关

| 原词 | 替换为 | 示例 |
|------|--------|------|
| 比赛 | 股票 | 比赛ID → 股票ID |
| 球队 | 公司 | 两支球队 → 两家公司 |
| 主队 | AAPL | 主队获胜 → AAPL上涨 |
| 客队 | TSLA | 客队落后 → TSLA下跌 |
| 对阵 | vs | A队 vs B队 |
| 比分 | 价格比 | 比分 2-1 → 价格比 2-1 |
| 进球 | 涨幅 | 进1球 → 涨1% |
| 球 | % | 2球 → 2% |

---

### 盘口相关

| 原词 | 替换为 | 示例 |
|------|--------|------|
| 盘口 | 指数 | 盘口变化 → 指数变动 |
| 亚盘 | 技术指标 | 亚盘水位 → 技术指标收益率 |
| 大小球 | 波动率 | 大小球初盘 → 波动率开盘价 |
| 初盘 | 开盘价 | 亚盘初盘 → 技术指标开盘价 |
| 水位 | 收益率 | 水位0.85 → 收益率0.85 |
| 大球 | 上涨 | 大球水位 → 上涨收益率 |
| 小球 | 下跌 | 小球水位 → 下跌收益率 |
| 半球 | 0.5% | 让半球 → 让0.5% |
| 一球 | 1.0% | 让一球 → 让1.0% |
| 平手 | 持平 | 平手盘 → 持平板 |

---

### 时间相关

| 原词 | 替换为 | 示例 |
|------|--------|------|
| 上半场 | 早盘 | 上半场进球 → 早盘涨幅 |
| 下半场 | 午盘 | 下半场无进球 → 午盘无波动 |
| 分钟 | 分钟 | 30分钟 → 30分钟（不变） |
| 中场 | 盘中 | 中场休息 → 盘中休息 |

---

### 告警类型

| 原词 | 替换为 | 示例 |
|------|--------|------|
| 达标 | 触发 | 水位达标 → 收益率触发 |
| 无进球 | 无波动 | 上半场无进球 → 早盘无波动 |
| 仅1球 | 仅1%涨幅 | 上半场仅1球 → 早盘仅1%涨幅 |
| 变化 | 变动 | 盘口变化 → 指数变动 |

---

### 其他

| 原词 | 替换为 | 示例 |
|------|--------|------|
| 监控 | 监测 | 盘口监控 → 指数监测 |
| 告警 | 通知 | 告警类型 → 通知类型 |
| 提醒 | 提示 | 邮件提醒 → 邮件提示 |
| 系统 | 平台 | 监控系统 → 监测平台 |

```
比赛ID: 2816062
告警类型: 上半场进球
时间: 2026-04-17 14:30:25

⚽ 上半场进球达标! A队 vs B队: 上半场2球(阈值2), 全场3球, 比分 2-1

---
此邮件由盘口监控系统自动发送
```

**修改后**:
```
股票ID: 2816062
通知类型: 早盘涨幅
时间: 2026-04-17 14:30:25

⚽ 早盘涨幅触发! AAPL vs TSLA: 早盘2%(阈值2%), 全场3%, 价格比 2-1

---
此邮件由股票监测平台自动发送
```
