#### ✨ 修改上下半场进球检测（需求1）

**原逻辑**: 一有进球就立即提醒
```python
if first_half_goals > old_fh_goals and first_half_goals > 0:
    trigger_alert()
```

**新逻辑**: 达到设定阈值才提醒
```python
if config.get('first_half_goal_enabled', False):
    threshold = config.get('first_half_goal_threshold', 1)
    
    if (first_half_goals >= threshold and 
        first_half_goals > state['first_half_last_goals'] and
        not state.get('first_half_reached', False)):
        trigger_alert(f"上半场{first_half_goals}球(阈值{threshold})")
        state['first_half_reached'] = True
    
    state['first_half_last_goals'] = first_half_goals
```

**特点**:
- ✅ 支持自定义阈值（1-10球）
- ✅ 每场比赛每个阶段只提醒一次
- ✅ 记录上次进球数，避免重复提醒

#### ✨ 新增无进球提醒功能（需求2）

**规则7: 有进球后到达时间提醒**
- 配置项: `has_goal_time_enabled`, `has_goal_time_minute`
- 逻辑: 如果比赛有进球，到达设定时间时提醒
- 示例: "⏰ 70分钟提醒! 比赛进行到第70分钟，已有2个进球"

**规则8: 上半场无进球提醒**
- 配置项: `first_half_no_goal_enabled`, `first_half_no_goal_minute`
- 默认: 30分钟
- 范围: 20-45分钟
- 逻辑: 上半场到设定时间仍无进球则提醒
- 示例: "⚠️ 上半场无进球! 比赛进行到第30分钟，上半场仍无进球"

**规则9: 下半场无进球提醒**
- 配置项: `second_half_no_goal_enabled`, `second_half_no_goal_minute`
- 默认: 70分钟
- 范围: 50-85分钟
- 逻辑: 下半场到设定时间仍无进球则提醒
- 示例: "⚠️ 下半场无进球! 比赛进行到第70分钟，下半场仍无进球"

#### ✨ 状态清理优化

在 `remove_match()` 和 `clear_matches()` 中添加了新状态的清理：
```python
if match_id in self.goal_threshold_states:
    del self.goal_threshold_states[match_id]
if match_id in self.no_goal_states:
    del self.no_goal_states[match_id]
```
