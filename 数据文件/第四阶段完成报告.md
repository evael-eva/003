## ⚠️ 注意事项

### 1. 服务器压力
- 并发数从8提升到15，对服务器的请求频率增加
- 如果被封IP，可以降低并发数回8或10
- 建议先测试小批量，确认稳定后再大规模使用

### 2. 网络稳定性
- 高并发可能受网络带宽限制
- 如果网络较慢，实际提升可能不如预期
- 建议在稳定的网络环境下使用

### 3. 动态调整
如果需要进一步调优，可以修改以下参数：

```python
# 在 odds_fetcher.py 中

# 并发数（根据服务器响应情况调整）

# 请求间隔（根据封禁风险调整）
time.sleep(random.uniform(0.1, 0.2))  # 可以改为 (0.15, 0.25) 等
```

```python
import time
from odds_fetcher import OddsFetcher

def test_batch_performance():
    """测试批量获取性能"""
    fetcher = OddsFetcher()
    
    # 准备测试数据（使用真实的比赛ID）
    match_ids = [
        '2816062', '2816063', '2816064', 
        '2816065', '2816066', '2816067',
        '2816068', '2816069', '2816070',
        '2816071'
    ]
    
    print(f"开始测试批量获取 {len(match_ids)} 场比赛...")
    start_time = time.time()
    
    results = fetcher.batch_fetch_initial(match_ids)
    
    elapsed = time.time() - start_time
    success_count = sum(1 for r in results.values() if not r.get('error'))
    
    print(f"\n测试结果:")
    print(f"  总耗时: {elapsed:.2f}秒")
    print(f"  平均每场: {elapsed/len(match_ids):.2f}秒")
    print(f"  成功: {success_count}/{len(match_ids)}")
    print(f"  失败: {len(match_ids) - success_count}")
    
    # 显示错误信息
    for mid, result in results.items():
        if result.get('error'):
            print(f"  比赛{mid} 错误: {result['error']}")

if __name__ == '__main__':
    test_batch_performance()
```
