# 告警弹窗优化说明

## ✅ 问题修复

### 问题描述
**修复前**: 告警弹窗是模态对话框，一次只能显示一个，必须关闭当前弹窗才能看到下一个。

**修复后**: 告警弹窗是非模态对话框，可以同时显示多个告警，互不阻塞。

---

## 🔧 技术实现

### 关键修改

**文件**: `alert_service.py`  
**方法**: `_show_popup_on_main_thread()`

#### 修改前（模态对话框）
```python
msg_box.exec_()  # 阻塞式，必须关闭才能继续
```

#### 修改后（非模态对话框）
```python
# 1. 设置为非模态
msg_box.setModal(False)

# 2. 设置窗口始终置顶
msg_box.setWindowFlags(
    msg_box.windowFlags() | 
    Qt.WindowStaysOnTopHint |  # 始终在最前
    Qt.WindowCloseButtonHint   # 显示关闭按钮
)

# 3. 使用show()而非exec_()
msg_box.show()  # 非阻塞式显示

# 4. 保持引用，防止被垃圾回收
if not hasattr(self, '_active_popups'):
    self._active_popups = []
self._active_popups.append(msg_box)

# 5. 清理旧弹窗（保留最近20个）
if len(self._active_popups) > 20:
    self._active_popups = self._active_popups[-20:]
```

## 📊 使用场景示例

### 场景1: 多场比赛同时告警

**情况**: 监控10场比赛，短时间内有3场触发告警

**修复前**:
```
时间线:
14:30:00 - 比赛A告警 → 弹窗1显示
14:30:05 - 比赛B告警 → 等待用户关闭弹窗1
14:30:10 - 比赛C告警 → 等待用户关闭弹窗1和2
```
**问题**: 用户可能错过重要告警

**修复后**:
```
时间线:
14:30:00 - 比赛A告警 → 弹窗1显示
14:30:05 - 比赛B告警 → 弹窗2显示（与弹窗1并存）
14:30:10 - 比赛C告警 → 弹窗3显示（3个弹窗同时可见）
```
**优势**: 所有告警一目了然

## 🔍 技术细节

### 为什么需要保持引用？

```python
self._active_popups.append(msg_box)
```

**原因**: Python的垃圾回收机制会自动销毁没有引用的对象。如果不保持引用，`msg_box`会在函数结束后被销毁，导致弹窗立即消失。

**解决方案**: 将弹窗对象保存到列表中，保持引用。

---

### 为什么要清理旧弹窗？

```python
if len(self._active_popups) > 20:
    self._active_popups = self._active_popups[-20:]
```

**原因**: 
- 避免内存泄漏
- 防止列表无限增长
- 保留最近的告警更有意义

**策略**: 保留最近20个，删除最旧的

---

### WindowStaysOnTopHint的作用

```python
Qt.WindowStaysOnTopHint
```

**效果**: 
- 弹窗始终显示在其他窗口之上
- 即使切换到其他程序，弹窗仍然可见
- 确保用户不会错过告警

**注意**: 某些系统可能需要额外权限

## ⚠️ 注意事项

### 1. 性能影响

- 每个弹窗占用少量内存（约1-2MB）
- 20个弹窗约占用20-40MB
- 对现代电脑影响极小

### 2. 用户体验

**优点**:
- ✅ 不会错过任何告警
- ✅ 可以同时查看多个告警

**缺点**:
- ⚠️ 可能积累太多弹窗
- ⚠️ 需要手动关闭
- ⚠️ 可能遮挡其他窗口

### 3. 系统兼容性

- ✅ Windows 7/8/10/11
- ✅ macOS
- ✅ Linux (X11)
- ⚠️ 某些窗口管理器可能不支持置顶
