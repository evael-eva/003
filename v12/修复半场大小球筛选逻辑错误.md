# v12 修复半场大小球筛选逻辑错误

## 🐛 问题描述

**用户报告：**
```
[21:56:54] 排除比赛2940644: 半场大球初盘1.25(=1.25)不在范围[0.75,
```

**问题分析：**
- 日志显示的是"半场大球初盘**1.25**"，这是**盘口大小（goal_line/handicap）**
- 但用户要求筛选的是**大球水位（over_odds）**
- **当前代码错误地检查了盘口大小，而不是水位** ❌

---

## 🔍 根本原因

### 错误的代码逻辑

**文件：** `v12/盘口监控邮件提醒.py` 第1026行

```python
# ❌ 错误：检查 handicap（盘口大小）
handicap_raw = ou_half_initial.get('handicap') or ou_half_initial.get('goal_line', '')

if handicap_raw:
    handicap_value = OddsFetcher._convert_handicap_to_number(str(handicap_raw))
    
    if self.half_ou_min <= handicap_value <= self.half_ou_max:
        # 保留比赛
    else:
        # 排除比赛：半场大球初盘1.25(=1.25)不在范围[0.75, 1.5]内
```

**问题：**
- `handicap` 字段存储的是**盘口大小**（如 1.25、1.5、2.0 等）
- `over_odds` 字段存储的才是**大球水位**（如 0.85、0.95、1.05 等）
- **用户想筛选的是水位范围，不是盘口范围！**

---

### 数据结构说明

**`ou_half_initial` 字典结构：**
```python
{
    'time': '初盘',
    'score': '',
    'over_odds': '0.95',      # ← 大球水位（应该检查这个）✅
    'goal_line': '1.25',      # ← 盘口大小（不应该检查这个）❌
    'handicap': '1.25',       # ← 转换后的盘口（不应该检查这个）❌
    'under_odds': '0.85',     # ← 小球水位
    'change_time': '',
    'status': '初'
}
```

**HTML表格列顺序（大小球）：**
```
索引0: 时间
索引1: 比分
索引2: 大球（大球赔率/水位）← over_odds ✅
索引3: 进球数（盘口大小）   ← goal_line ❌
索引4: 小球（小球赔率/水位）
索引5: 变化时间
索引6: 状态
```

## ✅ 修复方案

### 核心修改

**文件：** `v12/盘口监控邮件提醒.py`

#### 修改1: 更改筛选逻辑

**修改前（第1026-1056行）：**
```python
# ❌ 错误：检查 handicap（盘口大小）
handicap_raw = ou_half_initial.get('handicap') or ou_half_initial.get('goal_line', '')

if handicap_raw:
    try:
        from odds_fetcher import OddsFetcher
        handicap_value = OddsFetcher._convert_handicap_to_number(str(handicap_raw))
        
        if handicap_value is not None:
            if self.half_ou_min <= handicap_value <= self.half_ou_max:
                filtered_matches_after_half_ou.append(match)
                self.log_signal.emit(
                    f"保留比赛{mid}: 半场大球初盘{handicap_raw}(={handicap_value})在范围"
                    f"[{self.half_ou_min}, {self.half_ou_max}]内"
                )
            else:
                self.log_signal.emit(
                    f"排除比赛{mid}: 半场大球初盘{handicap_raw}(={handicap_value})不在范围"
                    f"[{self.half_ou_min}, {self.half_ou_max}]内"
                )
```

**修改后：**
```python
# ✅ 正确：检查 over_odds（大球水位）
over_odds_raw = ou_half_initial.get('over_odds', '')

if over_odds_raw:
    try:
        # 将水位转换为数字
        over_odds_value = float(over_odds_raw)
        
        # 检查水位是否在范围内
        if self.half_ou_min <= over_odds_value <= self.half_ou_max:
            filtered_matches_after_half_ou.append(match)
            self.log_signal.emit(
                f"保留比赛{mid}: 半场大球水位{over_odds_raw}在范围"
                f"[{self.half_ou_min}, {self.half_ou_max}]内"
            )
        else:
            self.log_signal.emit(
                f"排除比赛{mid}: 半场大球水位{over_odds_raw}不在范围"
                f"[{self.half_ou_min}, {self.half_ou_max}]内"
            )
    except (ValueError, TypeError) as e:
        self.log_signal.emit(
            f"排除比赛{mid}: 无法解析半场大球水位'{over_odds_raw}'"
        )
else:
    self.log_signal.emit(f"排除比赛{mid}: 无半场大球水位数据")
```

## 🎉 总结

### 问题根源

❌ 代码错误地检查了 `handicap`（盘口大小）  
❌ 应该检查 `over_odds`（大球水位）  
❌ 导致筛选逻辑完全错误  

### 解决方案

✅ 改为检查 `over_odds` 字段  
✅ 简化转换逻辑（直接 `float()`）  
✅ 更新UI标签和日志信息  
✅ 代码已通过语法检查  

### 最终效果

- ✅ 筛选逻辑正确：检查大球水位，不是盘口大小
- ✅ 日志清晰：明确显示"水位"，避免混淆
- ✅ 用户体验好：UI标签准确反映功能
